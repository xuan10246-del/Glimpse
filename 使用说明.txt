==================================================
           Glimpse · 瞬译 v3.1 - 使用说明
==================================================

一、如何安装与启动

  ▶ 方式 A：【标准安装版 Glimpse_v3.1.0_Setup_Win64.exe】（推荐）
    1. 双击运行「Glimpse_v3.1.0_Setup_Win64.exe」（如弹出 Windows Defender 蓝框保护提示，
       点击「更多信息」→「仍要运行」即可）。
    2. 在安装向导中自由选择安装路径（有 D 盘时默认 D:\Glimpse，可点「浏览」改至任意盘符）。
       所有运行环境、AI 模型与下载临时缓存均保存在所选安装目录内，绝不占用 C 盘空间。
    3. 安装最后一步会自动拉取便携 Python 3.12 与本地模型并启动；
       日常使用直接双击桌面「Glimpse 瞬译」快捷方式或安装目录内的「Glimpse.exe」即可（无黑框）。
    4. 需要卸载时，可在 Windows「设置 → 应用」直接卸载并选择一并清理全部模型释放空间。

  ▶ 方式 B：【绿色便携版 Glimpse_v3.1.0_Portable_Win64.zip】
    1. 请先将压缩包完整解压到非 C 盘目录（如 D:\Glimpse，切勿在压缩软件预览框里直接双击）。
    2. 双击「Glimpse.exe」（未初始化时会自动呼出初始化向导）或双击「一键安装运行.bat」。
    3. 初始化完成后，日常直接双击「Glimpse.exe」（或「启动翻译器.bat」）运行。

二、硬件兼容说明
  - 有 NVIDIA 独立显卡（建议 ≥6GB 显存）：自动开启 CUDA GPU 极速推理，画面和语音几乎秒译。
  - 无 NVIDIA 显卡（核显 / AMD 显卡 / 纯 CPU 笔记本）：支持自动切换 Vulkan 或 CPU 兼容模式，
    也可在「模型与引擎」接入 DeepSeek / 阿里云百炼 / 硅基流动 / Gemini 等云端 API（0 显存占用）。

三、主要功能怎么用
  1. 多区域取词：在控制中心点击「开始翻译」呼出译文底座与蓝色取景框；拖动框住字幕或评论区，
     点「+ 新增画面」可同时开多个框。
  2. 独立浮窗 / 防自捕 / 穿透锁定：点击卡片「独立浮窗」可拆出单窗口，并在「外观与窗口」为
     每个独立浮窗单独设置颜色、不透明度与描边。开启系统防自捕（WDA 0x11）后可将浮窗直接盖在
     取景框上方；开启「穿透锁定」可防止游戏中误触，按 Ctrl+Alt+U 可一键解除全部穿透。
  3. 只听某一个软件的声音：打开「控制中心」→「语音与隔离」→ 选「仅捕获指定软件音频」
     → 点击「点击拾取窗口」后点一下播放器或游戏窗口，即可屏蔽桌面其他网页/聊天杂音。
  4. 双向快翻胶囊：全局热键 Alt+T（文字输入）或 Alt+V（按住麦克风说话）可将中文实时翻成外语
     并自动复制/粘贴回游戏聊天框；支持极简悬浮条与独立底色/不透明度设置。

四、遇到启动异常怎么反馈？
  请改用双击目录中的「Glimpse_Debug.exe」（或「启动翻译器(调试日志).bat」），将弹出黑框中的
  报错信息以及同目录下的 translator.log / llama_server.log 一并截图反馈。
